This document describes a reproducible decode benchmark for a large mixture-of-experts language model whose expert weights are streamed from solid state storage rather than held in memory. The machine under test is a laptop with unified memory and several external drives attached over a high speed serial bus. Because the model is far larger than the available memory, every generated token requires the engine to fetch the weights of the experts that the router selects for that position, and the time spent waiting for those reads dominates the time spent on arithmetic. The benchmark therefore reports two separate quantities. The first is prompt processing throughput, measured by the additional latency that a long prompt adds before the first token appears. The second is generation throughput, measured over a fixed number of output tokens once decoding has begun. Both quantities are reported with the speculative drafter enabled and disabled, because a drafter changes the number of forward passes per committed token and therefore changes the read pattern as well. Readers comparing these figures with other engines should note that matching the token counts does not by itself make two systems comparable: the model, the quantization, the sampling settings, the storage layout and the definition of elapsed time all matter, and each of those is recorded alongside the numbers.
